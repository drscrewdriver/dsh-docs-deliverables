# 0.1.7 / 0.2.0 → 0.2.1 线迁移总览（alpha.1 ～ rc.4）

> 定位：0.2.1 线的**合并处方主文档**——逐段全量证据在 `../source-analysis/v0.2.1-*`（a.1/a.2/a.3/a.4/a.5/rc.1/rc.2/rc.3/rc.4 各四件套）；跨版本装载症状路由 → skill `dsh-plugin-peer-adapt`（§7 卡 VD-020-021-01..06）。
> 0.1.7→0.2.0 的迁移仍以 [v0.2.0-migration.md](v0.2.0-migration.md) 为主文档，本文只叠加 0.2.1 线增量。

## 0. 一句话判世代：闸门双时代

| 时代 | 宿主版本 | 判据 |
|---|---|---|
| 纯 peer 时代 | 0.1.7-rc.1 ～ **0.2.1-alpha.3** | 只读 `peerDependencies` 中 `@deepseek-ai/dsh*`；`engines.dsh` 不被读 |
| engines.dsh 时代 | **0.2.1-alpha.4** ～ 0.2.1-rc.1+ | 包自带 `engines.dsh` → 单独裁决（peers 全忽略）；无该键才回 peer 规则；`workspace:` 在该键非法；`engines` 形状错=拒载；拒载记录字段 `peers`→**`requirements`** |

**写法建议（二选一）**：
- **保守（推荐跨线包）**：不写 `engines.dsh`，peer 枚举照旧——两时代行为一致；
- **精确**：写 `engines.dsh` 就必须覆盖全部目标版本（`>=0.2.1-alpha.1 <0.2.2-0` 或枚举 `A || B || …`），并知晓它在 ≤a.3 宿主上完全无效（不报错、被忽略）。
- 消费拒载记录的代码：`record.requirements ?? record.peers` 双读。

## 1. 逐段必做清单（命中才动）

### a.2（669 提交 / 20 指南）——编排 API 与 provider 面
- 子代理激活统一化：`tool-subagent` 删 `backgroundMode`/`run_in_background`；`start()/startContinuable()`→`startActivation()`；`subagent-in-process-driver` 包移除；

### a.3（852 提交 / 14 指南）——**客户端契约符号首批成批删除**

- 凭据优先级反转（存储 > env）；deepseek-account 残留 `models` 加载即停；pi-ai `azure` 路由更名。

### a.4（89 提交 / 1 指南）——**闸门换代**（见 §0）+ plugin-market（`ctx.pluginMarket`/`plugins.tab`，纯增量）+ 门禁禁 module-scope await + 跨 host release 更新被拒。

### rc.1（纯 bump）
- 代码面与 a.5 逐面全等；runtime 字符串换 `0.2.1-rc.1`（范围命中判定对象）；vendor 转正式线（cordis 4.0.5 / schemastery 3.18.5 / loader 1.0.6 / hmr 1.0.20 等 9 件）。

### rc.2（两小功能包，零断裂）
- `web-deepseek-api`：DeepSeek Search/Fetch API 作为**既有 `ctx.web` 缝的 provider** 进门（settings 开关后，`tool-web` 工具名不变）；+1 同版本持久化承认 deepseek-search-thinking；
- `ui-deepseek-model-label-1017`：Flash 1017 徽章成为 `conversation.input.model.label` 槽**首个官方 occupant**（replaceRisk 升 `shadows-shipped-ui`）——同槽自挂标签的插件需运行态核对遮蔽竞争；
- ⚠ 后续实证补记：`ctx.web` 的 `searchProvider`/`fetchProvider` 钉选由构造期快照（可写私有字段）改 **volatile config 实时读**——接管型插件静默失效，需改 `settings.mutate` 持久钉选；
- 闸门/settings/vendor/slot 结构零 diff（探针 13 列与 rc.1 全等）；peer/engines 写法无需为 rc.2 改动（同三元组）。

### rc.3（导航条目自定义车；2026-10-23，指南 1 篇）
- **`startSession`/`openWorkspace`/`connectWorkspace` 空白会话复用**（唯一官方指南 `upgrade-guide/v0.2.1-rc.2/new-session-blank-reuse`）：签名不变、语义变——从每次新建改为按 preset 复用首个 unstarted/unarchived 空白；依赖"调用即全新 Agent"的集成需传 `{ agentPreset }` 排他；复用的空白保留创建时 preset 组成（改定义后需重启）；
- 新包 `client/ui-entry-customization`：左侧栏面板按钮 / View 页签 / guide 卡三域条目**用户可钉选/隐藏/收进 More**；**slot +3**（`sidebar.panellist.actions` / `conversation.session.header.views.actions` / `sidebar.right.tab.guide.actions`，0 删 0 改名）——插件入口可见性从此让渡给用户，展示质量/可达性自查；
- DeepSeek API-key 路由模型目录改**跟随官方 `/models` listing**（失败回落内建；新 additive volatile 键 `modelsTimeoutMs`/`modelsMaxAgeMs`）——精确断言 route 配置对象/内建 catalog 全集的测试会感知；
- 闸门/settings/vendor/缝/会话 V4 零 diff（gate=10/cf=78 与 rc.1/rc.2 同值）；枚举式 engines.dsh/peer 清单需加 `0.2.1-rc.3` 行，caret 免动。

### rc.4（纯修复车；2026-10-26，≠ master tip，指南 0 篇）
- 契约面**全零**：闸门/settings/vendor/缝/槽/`docs/` 整目录零 diff；rc.3↔rc.4 配对探针 14 列逐项全等；
- 三处运行态行为变（只伤探针/日志面不伤 API）：①`ui-conversation` View 页签全名 tooltip 改**估算溢出（>88px）才挂**，More 按钮文案不再含当前视图名（**内部 locale 键 `session.moreViewsCurrent` 删除**）——DOM 探针/e2e 文案锚需改；②`mcp-client` 对未宣告 resources 的服务器列表**短路空页、不触服务器**（消费形状 `{resources: []}` 不变）；③`llm-deepseek-account` 目录诊断 stdout→**stderr**（ACP stdout 由新 e2e 固化为仅协议消息）；

### rc.5（契约精化车；0.2.1 线现尾版 2026-10-29，≠ master tip（现 master tip=0.2.2-alpha.2），指南 1 篇）

- 枚举式 engines.dsh/peer 清单需加 `0.2.1-rc.5` 行，caret 免（同三元组）；官方升级指南 1 篇（目录 `docs/upgrade-guide/v0.2.1-rc.4/reasoning-body-props/`——**按迁移源命名而非目标版本**，同 rc.3 「New Session」指南命名惯例）。
