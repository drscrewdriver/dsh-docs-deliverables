# 0.1.7 / 0.2.0 → 0.2.1 线迁移总览（alpha.1 ～ rc.1）

> 定位：0.2.1 线的**合并处方主文档**——逐段全量证据在 `../source-analysis/v0.2.1-*`（a.1/a.2/a.3/a.4/a.5/rc.1 各四件套）；跨版本装载症状路由 → skill `dsh-plugin-peer-adapt`（§7 卡 VD-020-021-01..05）。
> 0.1.7→0.2.0 的迁移仍以 [v0.2.0-migration.md](v0.2.0-migration.md) 为主文档，本文只叠加 0.2.1 线增量。

## 0. 一句话判世代：闸门双时代

| 时代 | 宿主版本 | 判据 |
|---|---|---|
| 纯 peer 时代 | 0.1.7-rc.1 ～ **0.2.1-alpha.3** | 只读 `peerDependencies` 中 `@deepseek-ai/dsh*`；`engines.dsh` 不被读 |
| engines.dsh 时代 | **0.2.1-alpha.4** ～ 0.2.1-rc.1+ | 包自带 `engines.dsh` → 单独裁决（peers 全忽略）；无该键才回 peer 规则；`workspace:` 在该键非法；`engines` 形状错=拒载；拒载记录字段 `peers`→**`requirements`** |

**写法建议（二选一）**：
- **保守（推荐跨线包）**：不写 `engines.dsh`，peer 枚举照旧——两时代行为一致；
- **精确**：写 `engines.dsh` 就必须覆盖全部目标版本（`>=0.2.1-alpha.1 <0.2.2-0` 或枚举 `A || B || …`），并知晓它在 ≤a.3 宿主上完全无效（不报错、被忽略）。
- 消费拒载记录的代码：`record.requirements ?? record.peers` 双读。

## 1. 逐段必做清单（命中才动）

### a.1（266 提交〔201 非 merge + 65 merge〕/ 4 指南）

### a.2（669 提交 / 20 指南）——编排 API 与 provider 面
- 子代理激活统一化：`tool-subagent` 删 `backgroundMode`/`run_in_background`；`start()/startContinuable()`→`startActivation()`；`subagent-in-process-driver` 包移除；
- `{{cwd}}` 提示词变量移除（模板残留即发请求前失败）；`subagent-acp/sdk` 的 `cwd` 配置键删除；
- `BundleInfo.official`/`availability` **必填**新增（slot `PluginPackageRef` 同步）；
- session-title provider 换代（`registerSessionTitleLlmProvider` 等三导出删除）；
- `webRuntime`→`webStartup`；SSH/Node PTC `launch` 换代；`TerminalBlockLabels.commandLine()` 必填；tool presentation 拒 `both`。

### a.3（852 提交 / 14 指南）——**客户端契约符号首批成批删除**
- `projectUserText`/`UserTextReferences` → `UserTextRun`/`ReferenceChip`；
- `RenderMessageImages` → `MessageImages*Props`；槽 `conversation.message.images` 拆为 `conversation.chat.{message,user}.images`（旧名注入**静默失效**）；
- `OperatorPeer` 导出删除；非 page Connection 默认 `interactions:'none'`（`$events/$on/$stream` 不可用）；
- JSONL 持久包无 default 导出（命名空间插件）；JobId `<kind>-<16hex>`（删 `executionId`/`JobExecutionId`）；
- `tool-subagent` 拒 `persona`/`toolFilter`（改 `agentPreset`）；`installBundle` 已装即 `already-installed`；
- 凭据优先级反转（存储 > env）；deepseek-account 残留 `models` 加载即停；pi-ai `azure` 路由更名。

### a.4（89 提交 / 1 指南）——**闸门换代**（见 §0）+ plugin-market（`ctx.pluginMarket`/`plugins.tab`，纯增量）+ 门禁禁 module-scope await + 跨 host release 更新被拒。

### a.5（36 提交 / 1 指南）
- `AccountBonusNotification` 元数据可选/未校验（`JsonValue`）、`orderId` 任意串、空 `expiresAt`=永不过期、新增可选 `title`；
- 新槽 `conversation.input.model.label`；PTC instructions compose 化（prompt 形状敏感方重核）。

### rc.1（纯 bump）
- 代码面与 a.5 逐面全等；runtime 字符串换 `0.2.1-rc.1`（范围命中判定对象）；vendor 转正式线（cordis 4.0.5 / schemastery 3.18.5 / loader 1.0.6 / hmr 1.0.20 等 9 件）。
